# PAL v0.4.0

A major feature release of the Proteus Actuarial Library, building on v0.3.1.

## Highlights

### Distribution fitting, parameter uncertainty and model uncertainty

- Maximum-likelihood fitting is available across PAL's supported fitting families, with likelihood diagnostics and AIC/AICc model comparison.
- Fit severity distributions with reporting thresholds, right-censoring at policy limits, and observation weights where supported. Mean-excess diagnostics help assess large-loss tails.
- Opt-in joint asymptotic parameter uncertainty preserves estimated parameter dependence. Scenario-specific parameter draws respect admissible constraints and remain coupled with later loss simulation.
- `WeightedDistribution` combines candidate distributions using AICc weights or user-provided weights. Scenario sampling can retain the selected family and parameter vector across multiple losses, including compound frequency-severity simulation.

The default `.fit()` behaviour remains maximum likelihood with fixed parameter estimates. Asymptotic parameter uncertainty is available for regular fitted models; nonregular and boundary cases may require other methods.

### Correlation matrix modelling

- Higham nearest-correlation repair, including positive row/column weights and optionally preserved entries.
- Correlation matrix completion, hierarchical clustering, and clique/graph diagnostics.
- Gaussian and Student's t copulas and relevant multivariate distributions can automatically repair invalid matrices, issue a warning, and expose the adjusted matrix for review.
- Matrix repair uses NumPy or CuPy arrays. Some completion and clustering algorithms use CPU solvers.

### Multidimensional stratified sampling

- Randomised quasi-Monte Carlo sampling is integrated with PAL's stochastic distributions and copulas.
- Sobol-based multidimensional sampling can reduce simulation error for suitable models without requiring separate sampling code.

### Data interchange and persistence

- CSV, Parquet and pandas interchange for stochastic variables, nested portfolios and frequency-severity claim listings.
- Configurable dimension, simulation, event and value fields; MultiIndex column headers; round-trip imports.
- Filesystem support for cloud object storage through optional Azure and S3 drivers.
- Separate versioned PAL snapshots preserve variable structure and coupling information.

### Additional modelling and tooling improvements

- Generalised Beta Prime severity distribution; date-valued and categorical stochastic variables; stochastic variable lookup.
- Improved coupling consistency, numerical edge-case handling and CPU/GPU performance.
- Executable actuarial recipes, AI-oriented API discovery, documentation and an installable PAL modelling agent skill.
- Expanded unit tests and regression coverage, including MC/RQMC and GPU paths.

## Install and explore

```bash
pip install proteusllp-actuarial-library
```

For optional GPU support, install `proteusllp-actuarial-library[gpu]`.
For Parquet interchange, install `proteusllp-actuarial-library[parquet]`.
